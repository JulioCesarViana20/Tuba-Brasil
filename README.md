# 🛒 Tuba-Brasil — E-commerce

O **Tuba-Brasil** é um projeto de e-commerce front-end desenvolvido com foco em aprendizado prático de desenvolvimento web e manipulação dinâmica de dados com JavaScript puro. A plataforma simula a experiência completa de uma loja virtual, desde a navegação no catálogo até a finalização do pedido.

---

##  Funcionalidades

- **Catálogo de Produtos:** Renderização dinâmica dos itens disponíveis a partir dos scripts da aplicação.
- **Carrinho de Compras Funcional:** Adição, remoção e cálculo dinâmico dos itens selecionados pelo usuário.
- **Layout Responsivo:** Interface adaptada para navegação em dispositivos móveis e desktops.
- **Integração com WhatsApp:** Envio direto das informações do pedido/carrinho para atendimento rápido via mensagem.

---

##  Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Express.js
- Mercado Pago API
- Git & GitHub** Servidor local simples para execução da aplicação.

##💻 Como Executar o Projeto Localmente
Clone o repositório:
```
Bash
git clone [https://github.com/JulioCesarViana20/Tuba-Brasil.git](https://github.com/JulioCesarViana20/Tuba-Brasil.git)
Acesse a pasta do projeto:

Bash
cd Tuba-Brasil
Instale as dependências:

Bash
npm install
Inicie o servidor:

Bash
npm start
# ou
node server.js
Acesse no seu navegador:
Abra http://localhost:3000 (ou a porta informada no terminal).
```
